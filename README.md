# Informe Stellar / Drips

## Proyecto

Plataforma comunitaria para la preservación y transmisión de la lengua y memoria cultural de Santa María Cuquila.

## Objetivo

Analizar Stellar, Soroban y Drips desde una perspectiva de ingeniería de software, calidad, seguridad, financiamiento y viabilidad operativa, con el fin de determinar cómo estas plataformas de financiamiento descentralizado se integran (o entran en tensión) con el marco de calidad del proyecto (CMMI-DEV y MoProSoft), y con el contexto real de conectividad limitada de la región Mixteca.

## Resumen del informe

El documento cubre:

1. **Introducción y objetivo general** — marco y alcance del análisis.
2. **Materiales utilizados** — fuentes oficiales de SDF, Drips Docs, Plan de Calidad v1.0, CMMI-DEV y MoProSoft.
3. **Metodología**, con cinco ejes de análisis:
   - Desempeño técnico: comparación entre Stellar Community Fund y Drips Network.
   - Adaptación a contextos complejos: tensión entre verificación on-chain y operación offline-first, adaptación de REQM a entregables por tramos, gestión de la configuración y limitaciones prácticas.
   - Pensamiento crítico: riesgos de seguridad técnica, riesgos éticos/de transparencia y riesgos de auditoría de código abierto.
   - Actividades interdisciplinarias: vínculo entre las prácticas de calidad ya adoptadas y los requisitos económicos de Web3.
   - Aportaciones con inteligencia artificial: trazabilidad de los prompts usados durante la investigación y redacción.
4. **Conclusiones y referencias bibliográficas.**
